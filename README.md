# Pre-Deployment System State Audit Script

This Bash script captures and records the current state of a Linux system (*snapshot/baseline*) before performing any system upgrade or major maintenance. 

All collected system details are automatically saved into a log file in the user's home directory for easy reference during post-upgrade verification.

---

## 📌 Features

This script gathers comprehensive critical system data, including:

* **System & Hardware:** Hostname, current date/time, uptime, CPU specifications (`lscpu`), and memory usage (`free -h`).
* **Storage & Filesystems:** Disk space usage (`df -h`), block devices (`lsblk`), mounted filesystems (`mount`), and `/etc/fstab` contents.
* **Network & Security:** IP addresses (`ip a`), routing tables (`ip route`), open network ports (`ss -tuln`), firewall rules (`iptables` / `ufw`), and SELinux/AppArmor status.
* **Performance & Processes:** Top 20 processes by memory consumption (`ps aux`), failed `systemd` services, and the last 50 lines of the system journal (`journalctl`).
* **OS & Package Information:** OS release details (`/etc/os-release`), Kernel version (`uname -a`), environment variables, root crontabs, and installed package lists (`dpkg` or `rpm`).

## 🛠️ Requirements

* **Operating System:** Any Linux distribution (Debian, Ubuntu, RHEL, CentOS, Rocky Linux, etc.).
* **Privileges:** `sudo` or root privileges are recommended to collect complete security and system log details.
* **Tools:** `curl` installed (if using the quick run method).

## 🚀 Usage

### Quick Run via One-Liner

You can run the script directly from GitHub without manually downloading or saving the file:

```bash
curl -fsSL https://raw.githubusercontent.com/raznulasri/After-Upgrade-Healthcheck/main/Health-Check.sh | sudo bash
```
